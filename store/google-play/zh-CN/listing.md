# NeuroSound

## App name
Neurosound: 宇宙之声

## Short description
离线声音混音器、睡眠定时器和助你专注的声音。

## Full description
NeuroSound 是一款离线声音应用，用于睡眠、专注、冥想和放松。

可以单独播放一种声音，也可以在混音器中叠加最多四种。时间到了，睡眠定时器会缓缓降低音量并停止播放。锁屏控件让你无需重新打开应用即可暂停和继续。

• 雨声、森林、海浪等多种环境音
• 双耳节拍与单一频率音调
• 由你自己搭建的四轨混音器
• 睡眠定时器
• 收藏与已保存的混音
• 21 种应用语言
• 无账号、无广告、无分析 SDK
• 完全离线运行

双耳节拍和低频音调需要耳机，手机扬声器无法还原这些频率。

NeuroSound 不提供诊断、治疗，也不作任何医疗效果承诺。请将音量保持在舒适水平。
