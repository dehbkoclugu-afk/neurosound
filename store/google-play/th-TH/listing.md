# NeuroSound

## App name
NeuroSound

## Short description
มิกเซอร์เสียงออฟไลน์ ตั้งเวลานอน และเสียงช่วยจดจ่อ

## Full description
NeuroSound คือแอปเสียงแบบออฟไลน์สำหรับการนอน การจดจ่อ การทำสมาธิ และการผ่อนคลาย

เล่นเสียงเดียวก็ได้ หรือผสมได้สูงสุดสี่เสียงในมิกเซอร์ เมื่อหมดเวลา ตัวตั้งเวลานอนจะค่อย ๆ ลดเสียงแล้วหยุดเล่น ปุ่มควบคุมบนหน้าจอล็อกช่วยให้หยุดและเล่นต่อได้โดยไม่ต้องเปิดแอปใหม่

• ฝน ป่า ทะเล และเสียงบรรยากาศอื่น ๆ
• บีตไบนอรัลและโทนความถี่เดียว
• มิกเซอร์สี่แชนเนลที่คุณจัดเอง
• ตั้งเวลานอน
• รายการโปรดและมิกซ์ที่บันทึกไว้
• 21 ภาษาในแอป
• ไม่มีบัญชี ไม่มีโฆษณา ไม่มี SDK เก็บสถิติ
• ทำงานออฟไลน์ทั้งหมด

บีตไบนอรัลและโทนความถี่ต่ำต้องใช้หูฟัง ลำโพงโทรศัพท์สร้างความถี่เหล่านี้ไม่ได้

NeuroSound ไม่ได้ให้การวินิจฉัย การรักษา หรือคำรับรองผลทางการแพทย์ กรุณาตั้งระดับเสียงให้พอสบาย
