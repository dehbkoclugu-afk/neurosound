# 852Hz

## App name
852Hz: นอนหลับ ไบนอรัล โฟกัส

## Short description
เสียงช่วยนอน ไวท์นอยส์ ไบนอรัลบีต และ 432 Hz ใช้งานออฟไลน์ได้

## Full description
เสียงช่วยนอน เสียงฝน ไวท์นอยส์ บราวน์นอยส์ พิงก์นอยส์ ไบนอรัลบีต (เดลตา ธีตา อัลฟา เบตา แกมมา) และคลื่นความถี่โซลเฟจจิโอ เช่น 432 Hz, 528 Hz และ 852 Hz แอปสงบ ๆ สำหรับการนอน โฟกัส สมาธิ และการผ่อนคลาย

852Hz คือแอปเสียงแบบออฟไลน์สำหรับการนอน การจดจ่อ การทำสมาธิ และการผ่อนคลาย

เล่นเสียงเดียวก็ได้ หรือผสมได้สูงสุดสี่เสียงในมิกเซอร์ เมื่อหมดเวลา ตัวตั้งเวลานอนจะค่อย ๆ ลดเสียงแล้วหยุดเล่น ปุ่มควบคุมบนหน้าจอล็อกช่วยให้หยุดและเล่นต่อได้โดยไม่ต้องเปิดแอปใหม่

• ฝน ป่า ทะเล และเสียงบรรยากาศอื่น ๆ
• บีตไบนอรัลและโทนความถี่เดียว
• มิกเซอร์สี่แชนเนลที่คุณจัดเอง
• ตั้งเวลานอน
• รายการโปรดและมิกซ์ที่บันทึกไว้
• 21 ภาษาในแอป
• ไม่มีบัญชี ไม่มีโฆษณา ไม่มี SDK เก็บสถิติ
• ทำงานออฟไลน์ทั้งหมด

บีตไบนอรัลและโทนความถี่ต่ำต้องใช้หูฟัง ลำโพงโทรศัพท์สร้างความถี่เหล่านี้ไม่ได้

852Hz ไม่ได้ให้การวินิจฉัย การรักษา หรือคำรับรองผลทางการแพทย์ กรุณาตั้งระดับเสียงให้พอสบาย
