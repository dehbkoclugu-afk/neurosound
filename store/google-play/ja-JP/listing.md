# 852Hz

## App name
852Hz: 睡眠・バイノーラル・集中

## Short description
睡眠用の音、ホワイトノイズ、バイノーラルビート、432Hz。オフラインで使えます。

## Full description
睡眠用の音、雨音、ホワイトノイズ、ブラウンノイズ、ピンクノイズ、バイノーラルビート(デルタ、シータ、アルファ、ベータ、ガンマ)、432Hz・528Hz・852Hzなどのソルフェジオ周波数。睡眠、集中、瞑想、リラックスのための静かなアプリです。

852Hz は睡眠・集中・瞑想・リラックスのためのオフライン音アプリです。

音を単体で再生することも、ミキサーで最大4つまで重ねることもできます。時間になるとスリープタイマーが音量をゆっくり下げて再生を止めます。ロック画面の操作で、アプリを開き直さずに一時停止・再開ができます。

• 雨、森、海など複数の環境音
• バイノーラルビートと単一周波数のトーン
• 自分で組む4チャンネルのミキサー
• スリープタイマー
• お気に入りと保存したミックス
• アプリ内21言語
• アカウント・広告・解析SDKなし
• 完全オフラインで動作

バイノーラルビートと低い周波数のトーンにはイヤホンが必要です。スマートフォンのスピーカーでは再生できません。

852Hz は診断・治療・医学的効果の主張を行いません。音量は心地よい範囲に保ってください。
