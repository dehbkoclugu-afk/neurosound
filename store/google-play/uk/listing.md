# 852Hz

## App name
852Hz: Сон, Бінауральні ритми

## Short description
Звуки для сну, білий шум, бінауральні ритми та 432 Гц. Працює офлайн.

## Full description
Звуки для сну, шум дощу, білий, коричневий і рожевий шум, бінауральні ритми (дельта, тета, альфа, бета, гамма) та частоти сольфеджіо, як-от 432 Гц, 528 Гц і 852 Гц: спокійний застосунок для сну, зосередження, медитації та розслаблення.

852Hz — офлайн-застосунок зі звуками для сну, зосередження, медитації та відпочинку.

Увімкніть один звук окремо або поєднайте до чотирьох у мікшері. Коли час спливає, таймер сну плавно стишує звук і зупиняє відтворення. Керування з екрана блокування дозволяє поставити на паузу, не відкриваючи застосунок знову.

• Дощ, ліс, океан та інші звуки довкілля
• Бінауральні ритми й одночастотні тони
• Мікшер на чотири канали, зібраний вами
• Таймер сну
• Улюблене та збережені мікси
• 21 мова інтерфейсу
• Без облікового запису, реклами та аналітичних SDK
• Працює цілком офлайн

Бінауральним ритмам і низьким частотам потрібні навушники: динамік телефона їх не відтворює.

852Hz не встановлює діагнозів, не лікує та не обіцяє медичних результатів. Тримайте гучність на комфортному рівні.
