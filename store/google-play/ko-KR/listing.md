# NeuroSound

## App name
NeuroSound

## Short description
오프라인 사운드 믹서, 취침 타이머, 집중을 위한 소리.

## Full description
NeuroSound는 수면, 집중, 명상, 휴식을 위한 오프라인 사운드 앱입니다.

소리를 하나만 재생하거나 믹서에서 최대 네 개까지 겹쳐 들을 수 있습니다. 시간이 다 되면 취침 타이머가 볼륨을 서서히 낮추고 재생을 멈춥니다. 잠금 화면 컨트롤로 앱을 다시 열지 않고도 일시정지할 수 있습니다.

• 비, 숲, 바다 등 여러 환경음
• 바이노럴 비트와 단일 주파수 톤
• 직접 구성하는 4채널 믹서
• 취침 타이머
• 즐겨찾기와 저장한 믹스
• 앱 언어 21종
• 계정, 광고, 분석 SDK 없음
• 완전히 오프라인으로 작동

바이노럴 비트와 낮은 주파수 톤은 이어폰이 필요합니다. 휴대폰 스피커로는 재생되지 않습니다.

NeuroSound는 진단, 치료, 의학적 결과를 주장하지 않습니다. 볼륨은 편안한 수준으로 유지하세요.
